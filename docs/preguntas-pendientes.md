# Preguntas pendientes

Esta lista se responde dentro del repo, en una conversacion larga. No son decisiones tomadas.

- Alcance de v0.1: que debe hacer el cliente minimo para ser util sin crecer de mas.
- Sync y async: si v0.1 parte solo sync o incluye ambos desde el inicio.
- Dependencias runtime: que entra como base y que queda fuera para mantener instalacion liviana.
- Modelo de datos: como representar indicador, punto de serie y foto actual sin atar la API antes de tiempo.
- Manejo de errores: que casos cubre el SDK y que mensajes muestra en espanol.
- Fechas: como valida y normaliza anios y fechas puntuales.
- Cache: si v0.1 incluye cache en memoria o disco, y con que reglas.
- Salidas de datos: si conviene ayudar con pandas o polars, o dejar eso para despues.
- CLI: si tiene sentido un comando chico o si solo sera libreria.
- Versionado y releases: ritmo de 0.x y reglas para cambios con quiebre.
- Publicacion: cuando subir a PyPI y con que nombre final si `mindicador` sigue libre.
