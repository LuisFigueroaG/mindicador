# mindicador

SDK simple en Python para consultar mindicador.cl.

Estado: base inicial. Aun no hay cliente instalable. No publiques ni uses este paquete todavia.

Que sera: un cliente pequeno y tipado para leer indicadores economicos chilenos desde Python, pensado para uso directo en scripts y analisis.

Fuente de datos: mindicador.cl. Proyecto independiente, sin afiliacion con este SDK ni con el Banco Central de Chile.

Temas pendientes: el diseno de la API se conversa dentro de este repo. Ver `docs/preguntas-pendientes.md`.
