# Contribuciones

Por ahora no acepto contribuciones externas.

El repo es publico para lectura. Issues, Discussions y Wiki estan apagados. Si ves un error, espera a que abra una via de reporte.

Cuando abra el proyecto, voy a pedir:

- Cambios pequenos y enfocados.
- Tests que pasen con `uv run pytest -q`.
- `uv run ruff check .` y `uv run ruff format --check .` en verde.
- `uv run pyright` en verde.
